myKyar ကို သုံးတဲ့အခါ ဘယ်လိုအချက်အလက်တွေ သုံးနိုင်သလဲဆိုတာ ဒီစာမျက်နှာမှာ ရှင်းပြထားပါတယ်။

ကစားချိန် အချက်အလက်

လက်ရှိ version မှာ account ဖွင့်ဖို့၊ နာမည်၊ email ဒါမှမဟုတ် ဖုန်းနံပါတ်ပေးဖို့ မလိုပါဘူး။ Local နဲ့ စက်ရုပ်ပွဲရဲ့ ကျားကွက်၊ အလှည့်နဲ့ Undo history ကို browser memory ထဲမှာ ယာယီထားပါတယ်။ App က အဲဒီ history ကို database ထဲသိမ်းတဲ့ feature မထည့်ထားပါဘူး။ Page ကို reload ဒါမှမဟုတ် ပိတ်လိုက်ရင် လက်ရှိပွဲကို ပြန်ဆက်နိုင်တဲ့စနစ် မရှိပါဘူး။

Online / Remote ကစားခြင်း

Online ပွဲမှာ room identifier၊ ကျားကွက်၊ အလှည့်၊ ရွှေ့ကွက်နဲ့ နောက်ပွဲအရောင်ရွေးမှုကို ကစားဖော်ရဲ့ browser နဲ့ ဖလှယ်ပါတယ်။ PeerJS signaling service နဲ့ WebRTC ကို ချိတ်ဆက်ဖို့ သုံးပါတယ်။ ချိတ်ဆက်တဲ့အခါ IP address နဲ့ network connection အချက်အလက်တွေကို ကစားဖော်နဲ့ signaling / connection service တွေ သိနိုင်ပါတယ်။ တိုက်ရိုက်ချိတ်ဆက်မှုမရတဲ့ network တွေမှာ relay service က connection ကို ဖြတ်သန်းပေးနိုင်ပါတယ်။ Room code / invite link ကို မိမိကစားလိုသူနဲ့သာ မျှဝေပါ။

Hosting နဲ့ ပြင်ပဝန်ဆောင်မှုများ

Website hosting၊ PeerJS library ရယူတဲ့ CDN နဲ့ connection service တွေက request၊ IP address၊ browser / device အချက်အလက်နဲ့ အချိန်လို technical information တွေကို သူတို့ရဲ့ policy အတိုင်း ကိုင်တွယ်နိုင်ပါတယ်။ ဒီ app code မှာ analytics၊ advertising tracker ဒါမှမဟုတ် tracking cookie ထည့်မထားပါဘူး။ Browser နဲ့ ပြင်ပဝန်ဆောင်မှုတွေရဲ့ data handling ကိုတော့ ဒီစာမျက်နှာက အစားထိုးမပေးပါဘူး။

Coffee၊ Burger၊ Big Meal links

Online connection အချက်အလက်ကို မမျှဝေချင်ရင် Local ဒါမှမဟုတ် စက်ရုပ် mode ကို သုံးနိုင်ပါတယ်။ Website ဖွင့်တာကြောင့် hosting / CDN request တွေတော့ ရှိနိုင်ပါတယ်။ Online ပွဲကနေ ထွက်ချင်ရင် “ထွက်မယ်” ကိုနှိပ်ပါ။ Browser tab ကိုလည်း ပိတ်နိုင်ပါတယ်။ ကစားဖော်ဆီ ရောက်ပြီးသား အချက်အလက်ကို ပြန်ဖျက်ပေးနိုင်မယ်လို့ မအာမခံပါဘူး။
